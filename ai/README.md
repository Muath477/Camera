# الذكاء الاصطناعي في Camera

ثلاثة أجزاء:

| المجلد | ما هو |
|---|---|
| `embedder/` | خدمة تحوّل النص والصور إلى متجه من 512 بُعداً في فضاء CLIP ViT-B/32. النص عبر مُرمِّز متعدد اللغات، فالسؤال بالعربية يجد الصور كما يجدها بالإنجليزية. تعمل على المعالج بلا بطاقة رسوميات، والنماذج تُحمَّل وقت البناء فتعمل بلا إنترنت. |
| `train/` | ترتيب الصور المصنّفة في مجموعة تدريب وتحقق (`prepare.py`)، وتدريب مصنِّف خطي فوق متجهات CLIP (`train.py`). |
| `models/` | مخرجات التدريب (`probe.json` و`report.json`). لا تُرفع إلى المستودع. |

## كيف يعمل البحث بالوصف

1. جهاز الحافة يأخذ لقطة الحدث من Frigate ويرسلها إلى `embedder` على الجهاز نفسه (`embedder_url` في `agent.yaml`)، فلا تغادر الصورة الموقع لهذا الغرض.
2. يُرسل المتجه مع الحدث إلى السحابة ويُخزَّن في عمود `embedding` (pgvector).
3. عند البحث، الخادم يرسل النص إلى `embedder` (`EMBEDDER_URL`) ويرتّب الأحداث بأقرب مسافة.

في بيئة التطوير، الجهاز الافتراضي يرسم مشهداً بسيطاً لكل حدث (شخص، سيارة، دراجة نارية، شخص يحمل صندوقاً) ويضمّنه بنفس الطريقة.

## التدريب على فئاتك

التدريب هنا لا يعيد تدريب CLIP. يدرّب طبقة خطية واحدة فوقه، فيكفيه عشرات الصور لكل فئة، ويعمل على حاسوب عادي خلال دقائق. يناسب فئات خاصة بمنشأتك مثل «زي الموظفين» أو «توصيل» أو «رف فارغ».

```bash
# 1) ضع الصور: raw/<الفئة>/*.jpg  (لقطات من كاميراتك، فئة لكل مجلد)
# 2) رتّبها: إزالة المكرر، تصغير، تقسيم 80/20 لكل فئة
docker compose -f deploy/dev/docker-compose.yml run --rm -v "$PWD/ai:/ai" --entrypoint python embedder /ai/train/prepare.py /ai/raw /ai/dataset
# 3) درّب
docker compose -f deploy/dev/docker-compose.yml run --rm -v "$PWD/ai:/ai" --entrypoint python embedder /ai/train/train.py /ai/dataset /ai/models
# 4) أعد تشغيل الخدمة فتقرأ ai/models/probe.json وتجيب على POST /classify
docker compose -f deploy/dev/docker-compose.yml restart embedder
```

لتجربة المسار بلا كاميرات: `go run ./cmd/device-sim -dump-scenes ai/raw -n 40` يكتب مشاهد مرسومة لأربع فئات. النتيجة تثبت أن المسار يعمل، لكنها ليست نموذجاً صالحاً للاستخدام الحقيقي؛ ذلك يحتاج لقطات من كاميراتك.
